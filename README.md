# 📚 Django Book Manager

A full-stack Django web application designed to manage book inventory efficiently. Users can view a list of books, check detailed information for each book, add new entries, edit existing records, and delete books.

---

## ✨ Features

* **Book Overview**: Clean tabular display of all available books with essential details.
* **Detailed View**: View individual book details including title, author, category, publication date, and description.
* **Manage Books**: Easily add, edit, or delete book entries.
* **Responsive UI**: Styled with Bootstrap for a clean and mobile-friendly interface.

---

## 🛠️ Tech Stack

* **Backend**: Python, Django
* **Frontend**: HTML5, CSS3, Bootstrap 5
* **Database**: SQLite3 (default Django DB)
* **Version Control**: Git, GitHub
